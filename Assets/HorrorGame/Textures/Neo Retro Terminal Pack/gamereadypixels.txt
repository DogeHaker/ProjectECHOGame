🛠️ HOW TO USE
1. Importing Assets:

Drop the asset folders directly into your preferred game engine (Unity, Godot, Unreal Engine, GameMaker, etc.).

Crucial for Pixel Art/Lo-Fi Look: To prevent your engine from blurring the textures, change the texture Import Settings: Set the Filter Mode to Point (No Filter) or Nearest Neighbor, and set compression to None/High Quality.

2. Slicing Sprite Sheets:

Grid and sprite sheets are laid out symmetrically. You can easily slice them using your engine's built-in Sprite Editor using rectangular or grid slicing tools.

3. Adding Text to Screens & HUD:

All UI elements are intentionally textless.

To display text or numbers, simply place a dynamic text UI component (such as UI Text, TextMeshPro, or a Label node) directly over the blank containers inside your game engine. This makes the pack completely compatible with localization and multiple languages.

4. Using Seamless Textures:

Apply the tileable textures to your 3D materials or 2D tilemaps. Ensure the texture wrap mode is set to Repeat (or Tile) to enable infinite scaling without visible seams.
